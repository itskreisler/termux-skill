# termux-skill

**One command. Termux API skill for your AI agent. Installed.**

```bash
npx -y termux-skill
```

Outputs the Termux API SKILL.md with 70+ commands for controlling Android devices: camera, sensors, GPS, SMS, notifications, clipboard, TTS, torch, WiFi, battery, and more.

Auto-detects native Termux, proot-distro, or falls back to SSH on port 8022.
